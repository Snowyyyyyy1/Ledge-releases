# Ledge

把窗口收到屏幕边缘,需要时再叫回来的 macOS 工具。
[源码仓库](https://github.com/Snowyyyyyy1/Ledge)是私有的;安装包发在本仓库的
[Releases](../../releases),应用内更新检查也读这里。

把某个应用加入列表后,把它的窗口拖到屏幕左右边缘松手即收纳——屏幕边上只留一条
细指示条,悬停展开、移开收起;也可以用快捷键把当前窗口一键收起。窗口本体不动,
只是被挪到屏幕外面,随时完整取回。

**系统要求**:macOS 15 及以上。

## 安装

1. 从 [Releases](../../releases/latest) 下载 `Ledge-<版本>.dmg`;
2. 打开 DMG,把 `Ledge.app` 拖进「应用程序」;
3. **首次打开要右键点图标 →「打开」**,不能双击。这个包没有 Apple Developer ID
   签名(那需要付费开发者账号),Gatekeeper 会拦一次;选「打开」之后以后正常双击。
4. 首次启动会请求**辅助功能**权限——移动别的应用的窗口必须有它。授权后自动就绪,
   不用重启。

从 v0.1.4 起,安装包用固定证书签名:**辅助功能授权在版本更新后保持有效**,
不需要每次升级重新授权。(从 v0.1.3 或更早升上来的那一次仍要重新授权一回,
那是签名身份切换的一次性代价。)

### 权限一览

| 权限 | 必需? | 用途 |
|---|---|---|
| 辅助功能 | 必需 | 移动、隐藏、恢复别的应用的窗口 |
| 屏幕录制 | 可选 | 仅「悬停预览 / 固定画面」功能显示窗口实时画面;不开这两个功能就不需要 |

## 更新

Ledge 内置自动更新(默认每周检查,可在「设置 → 通用」改频率或「立即检查」)。
更新包同样发在本仓库,由 EdDSA 签名校验。

## 隐私与诊断

- **不收集任何数据。** 没有分析、没有账号、不联网上报使用情况。
- 唯一的例外是**崩溃报告,且默认不上传**:Ledge 崩溃或卡死后,下次启动会问你
  是否把系统生成的诊断文件发给开发者(可选「自动上传 / 仅这次 / 不上传」,
  之后随时在「设置 → 通用 → 诊断」更改;选「从不上传」会同时清掉本地暂存)。
  报告内容为系统诊断文件与 Ledge 自身日志,**从不包含窗口标题、剪贴板等内容**。
- 运行日志在 `~/Library/Logs/Ledge/`(「设置 → 诊断 → 在访达中显示」可直达),
  反馈问题时把最新的 `ledge.log` 一并附上最有帮助。

## 校验下载

每个版本附带 `.sha256` 文件:

```
shasum -a 256 -c Ledge-<版本>.dmg.sha256
```

## 卸载

1. 先退出 Ledge(状态栏菜单 → 退出;所有被收纳的窗口会自动放回屏内);
2. 把 `Ledge.app` 从「应用程序」拖进废纸篓;
3. 想清干净数据的话,在终端执行:

```sh
rm -rf ~/Library/"Application Support"/Ledge \
       ~/Library/Logs/Ledge \
       ~/Library/Caches/com.snowyy.ledge \
       ~/Library/HTTPStorages/com.snowyy.ledge
defaults delete com.snowyy.ledge 2>/dev/null
```

「系统设置 → 隐私与安全性」里的辅助功能/屏幕录制授权条目可顺手移除;
「登录时打开」如启用过,删除应用后系统会自行清掉失效项。

## 窗口不见了?

Ledge 的窗口只是被挪到屏幕外,没有被关闭:

- 状态栏菜单里列出了所有已收纳的窗口,点击即放回;「全部放回」一键恢复;
- 退出 Ledge 也会把所有窗口放回原位;
- 即使 Ledge 崩溃,重启它会按崩溃前的记录自动找回窗口。
